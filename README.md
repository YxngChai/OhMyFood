# OhMyFood 🍽️

OhMyFood is a responsive restaurant booking website built as part of the OpenClassrooms Web Developer path.  
The goal of the project is to integrate a mobile-first interface using **HTML5** and **SCSS**, with modern CSS animations and accessibility best practices.

---

## Features

- Fully responsive design (mobile-first approach)
- CSS animations:
  - Loading spinner overlay
  - Menu item staggered appearance
  - Heart “favorite” hover animation
  - Interactive validation tick on menu items
- Semantic HTML and accessible structure (ARIA labels, meaningful tags)

## Development Workflow

This project uses **Node.js (npm)** to automate the development process.

It includes:

- SCSS compilation (Sass)
- Live-reload development server (BrowserSync)
- Asset and HTML file copying
- CSS post-processing (Autoprefixer + cssnano)
- Watch mode for instant updates during development

## Built With

- HTML5
- SCSS (Sass)
- CSS3 (Flexbox + Grid)
- SVG icons
- Google Fonts (Roboto & Shrikhand)
